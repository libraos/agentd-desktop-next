# Layout references

Screenshots of other products, kept as a reference for layout only. Names, addresses, session titles, conversation text and command lines are masked. Do not copy another product's wording, icons or artwork into AgentD Desktop, and do not publish these files.

The design they illustrate is in the notes in [agentd/design](..).

## Main window (Claude Code's desktop app)

| File                               | What to take from it                                                                                                                                                                                                                                                             |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `layout-3-most-needed-marked.png`  | The three areas marked in red are what the base app lacks and we build first: the sidebar with projects as headings and their sessions under them; the **Background tasks** list at the foot of the right panel; the **Background tasks** pane with "Running N" and "Finished N" |
| `layout-2-full-window.png`         | The whole window: sidebar, conversation, right panel (Environment, Context, Outputs, Background tasks), and the Background tasks pane. A running task shows its command and output; a finished one shows its duration or Stopped / Failed                                        |
| `layout-1-sidebar-and-context.png` | The sidebar grouping and the Context and Outputs sections                                                                                                                                                                                                                        |
| `chat-code-switch.png`             | The two-state switch at the top of the sidebar. Ours switches between Chat (the conversation alone) and Code (the conversation with the right panel, diff, files and terminal)                                                                                                   |

In the masked sidebar each group is one project: a heading with the project's name and where it runs, then one row per session.
